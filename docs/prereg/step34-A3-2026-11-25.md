## 2. V2 replaced (before any judged result)
**Why:** the r1/A1 V2 (ClA tied to CdA by L/D) put L/D on its 4.4 bound in every fold of a code test (disclosed in the status, not counted).
By A1 §3 a bounded V2 cannot pass, so running it would spend one of the two attempts on a likely fail. Steps 31/32 showed the F1 lesson:
lateral, braking and traction need their own limits, or downforce and drag soak up corner and straight errors.

**New V2 = V1 + decoupled limits** (flag `LAPSIM_WEC_DECOUPLED=on`), through the series-generic kernel hooks (unset = today):
- lateral `car.lateralCap = {kind: 'quad', a0, k}` (on main), braking and traction `car.decoupled = {b0, b2, aTr}` (step 31 hook, ported
  unchanged; all × track grip and the same friction ellipse);
- CdA fitted against trap speeds (at position) with the published prior (A1: 1.04 m² ± 10 %, Hypercar); power from the event BoP;
- priors (penalty w·(ln(x/x0)/sd)², w = 0.5 s², the A1 form), from published class specs where they exist:

| Parameter | Hypercar x0 (sd) | Source | LMGT3 x0 (sd) | Source |
|---|---|---|---|---|
| CdA | 1.04 m² (10 %) | CzA window / L/D (A1) | none | data limit |
| a0 (lateral at 0 speed) | 16.7 m/s² = 1.7 g (15 %) | no published μ: weak prior | 14.7 m/s² = 1.5 g (15 %) | weak prior |
| k (lateral aero) | μ·ρ·CzA/(2m) = 1.7·1.2·4.15/(2·1050) = 0.0040 1/m (20 %) | CzA window 4.05–4.25 m², BoP mass | 0.0015 1/m (50 %) | weak prior, no published GT3 aero |
| b0, b2 (braking) | 8.63 m/s², 0.003234 1/m (15 %) | iRacing GTP envelope, model (iRacing) | 13.7 m/s², 0 (30 %) | weak prior; ABS table = data limit |
| aTr (traction) | 9.8 m/s² (30 %) | weak prior | 9.8 m/s² (30 %) | weak prior |
If the owner gives iRacing access, the GT3/GTP derived table replaces the LMGT3 braking/traction priors before the judged runs (never after).
- Same rules as A1: any parameter of the full fit at a bound or at > 2 prior sd = model error; a variant with one cannot pass.
- m stays 2 (V1, new V2), k = 1.45, sign-flip p < 0.08.

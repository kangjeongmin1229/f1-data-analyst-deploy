## 2. Power — measuring point
- **Kernel:** `pIce` is power before the driveline; drive force = (pIce·etaDrive + pErs·etaErs·etaDrive)/v (`worker/lapsim/kernel.js`
  l. 419), `etaDrive` 0.95 for every WEC class (`series.js` `common`). Hypercar ERS is booked inside the drive power (l. 437). Shipped wheel
  power = 0.95 × pIce: Hypercar 475 kW, LMGT3 361 kW. In V the kernel input is **pIce = P_wheel / etaDrive**.
- **LMGT3 — rule:** 2026 LMGT3 TR (WMSC 16.10.2025) Art. 5.2 p. 9: "The powertrain performance (power output at the wheel) must be declared
  and homologated by the manufacturer".
- **Hypercar — ASSUMPTION:** 2026 LMH TR Art. 5.6.1 p. 27 and 2026 LMDh TR Art. 5.5.1 p. 33 require homologated sensors "which measure the
  torque supplied to each driveshaft". LMH Art. 5.1.1 p. 22: power limits "are defined in the energy flow diagram shown in Appendix 4";
  Appendix 4 is not public. Treating the BoP kW as wheel (driveshaft) power is our reading of these articles, labelled **"assumption"**.

## 5. Identifiability (reported, decides what can be claimed)
At each fold's optimum: numerical Hessian in log-parameters (central differences, step 1 %), covariance = H⁻¹, correlation matrix,
condition number, posterior sd vs prior sd. |r| > 0.9 or posterior sd > 0.8 × prior sd = **"not separable by the data"** (value = prior's, ±).

## 6. Tests and success rule — held-out lap, unit = track
- Base = the same build with today's class fit, in the same run family (reference 45566297648).
- **Family H (Hypercar, LMH + LMDh pooled):** d = |V err| − |base err| per track (seasons and classes averaged).
  MDE (n = 8 tracks, per-track SD 0.376 pp) = 1.84 · 0.376 / √8 = 0.244 pp.
- **Family G (LMGT3) joins only if its power check passes**, computed on the base run before V is opened: MDE = 1.84 · SD_track / √n
  ≤ 0.244 pp. If it fails, LMGT3 is report-only.
- **α:** m = 1 → one-sided 95 %. If LMGT3 joins: **m = 2, one-sided 97.5 % per family** (Bonferroni, `kForVariants(2, n)`); MDEs recomputed
  with that t (family H, n = 8: MDE 0.314 pp).
- **PASS = for every tested family, all three:**
  1. **no fitted parameter at a bound** — ClA, CdA, μy, and P for LMGT3 — in **every class-season and every fold**; a value **within 0.5 %
     of a bound counts as at the bound**;
  2. **lap held-out harm: upper bound of mean d ≤ 0.15 pp**;
  3. **no single track worse than +1.0 pp** (d ≤ +1.0 pp for every track of the family).
  Anything else = FAIL. Guards (any failure = FAIL): energy closure ≤ 0.1 %, F1/FE byte-identical (wec_only), compute ≤ +20 %.
- **"Better"** only if mean gain −d̄ ≥ that family's MDE; otherwise a PASS is reported as **"not worse"**.
- A parameter > 2 prior sd from its prior is reported as a model-error flag (no pass role).

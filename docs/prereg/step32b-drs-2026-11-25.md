## 3. Main test — DRS bias on held-out tracks (≤ 2025)
- Cases: the pinned v2 pooled DRS Δ cases (`scripts/sim/data/f1-delta/f1-delta-cases-pooled-2026-11-24.csv`, sha256 5a153cf1…,
  2023–25, 125 event × zone cases). No case enters any fit (the fit uses pole laps).
- Held-out tracks: every case is predicted with **no parameter from its own track**: the calibration's 2025 car with grip and drag
  factor = median over the other 2025 tracks (`F1_DELTA_HELDOUT=on`, `scripts/sim/f1-delta-bench.mjs`). Base and candidate use the same
  rule on their own calibration. Caveat stated: the base's fitted CdA uses every track's pole lap (one global parameter); the
  candidate's CdA is fixed, so it carries no track information.
- Error per case e = pred − meas (s); bias = mean e. Statistic R = 1 − |bias_cand| / |bias_base|.
- Test (one-sided): paired event bootstrap (unit = event, both sets resampled with the same events, 2000 draws, seed 7); one-sided
  95 % lower bound of R = 5th percentile. **Success: lower bound ≥ 0.40** (H0: R ≤ 0.40 rejected at α = 0.05).
- Power (prior evidence, not this run): step 32 C3 on the same cases gave bias −0.119 s [−0.146, −0.098] vs base −0.292 s
  [−0.32, −0.27] → R ≈ 0.59, SE(R) ≈ 0.045, so a true R ≥ 0.47 passes. Step 28 gave −0.29 → −0.10 s in every attempt.

## 2. Geometry quality per circuit (central 1)
FE street circuits have no TUM line. Source per circuit: official FIA Formula E map vector line, or OSM ways matched to the map
(Mexico), or an existing simulator track (Monaco). Metrics per circuit:
- closure of the map line: |Σκ·ds − 360°| (from the build); length ratio racing line ÷ official printed length;
- corner count: simulated corners (peaks of |κ| over 25 m smoothing with radius < 100 m, peaks closer than 50 m merged) vs the
  largest printed turn number on the map that gave the line.
**Good** = closure ≤ 5°, ratio 0.95–1.005, |Δcorners| ≤ 2. Other circuits are **report-only**: they stay in the fit, but are not in
any decision group.

## 3. Noise floors σ_meas (Al Kamel, `fe-cars.csv.gz`, Gen3 Evo seasons 2025–26, dry)
- **Lap:** per event with both qualifying groups (A, B, 300 kW, same session day): d = ln(best A / best B). σ_stat = SD(d)/√2,
  σ_sys = |mean d|/√2 (group order / evolution), σ_meas,lap = RMS(d)/√2 (= stat ⊕ sys). In % of lap.
- **Sectors:** same with each car's best sector s1, s2, s3 in group A vs group B: σ_meas,sector k, in % of that sector.
- Second estimate (report only): best lap vs ideal lap (sum of best sectors) of the fastest car per duel row.
- C1 ratio = held-out RMS ÷ σ_meas,lap (target ≤ 1.2).

## 4. Gen3 Evo model variant (flag `car.brakeAxle`, off; m = 1)
- **V1 (rule, correctness): blended braking with the rear regen limit.** Gen3 and Gen3 Evo have no rear friction brakes; the rear axle
  is braked only by the rear motor, max 350 kW electrical of the 600 kW regen (250 front + 350 rear). Kernel hook, braking pass only:
  a ≤ [μx·N_front(a) + min(μx·N_rear(a), P_rear/(η·v)) + drag + roll]/m, with load transfer h/wb, η_regen 0.95 (fe-gen4.js prior
  0.90–0.97). Unset = byte-identical (test). Front = friction + front regen, so the front side has no power cap.
- Not run as variants (written reasons):
  - sectors in the objective: no sector-line position is in any pinned input. The maps print i1/i2 only as a legend entry
    (115 of 122 maps); the marks on the track are graphics, not text. Needs a data-fix step that reads them. The primary metric
    "held-out sector RMS vs σ_meas" is therefore **not computable in step 35**; σ_meas,sector is still measured;
  - power modes: already by rule (`feCarFor`); group laps are no longer targets (§1);
  - tyre grip: one grip per rule set with the G term; the all-weather tyre has no public grip data → stays a prior (fe-gen4.js);
  - Attack Mode: physics check only (§6), no fitted parameter.
- **Power check first.** SD of the per-layout paired squared-error loss of V1 vs baseline with all rows fitted (no held-out) →
  UB half-width k·SD/√n, k = kForVariants(1, n), n = good layouts. If > 0.10 pp the run is "not judgeable at this n", no attempt spent.
- **Validation:** leave-one-event-out (event = layout × season), score per layout (seasons averaged), good layouts only.
  Guard: lap paired RMS-loss UB ≤ 0.10 pp. Primary sector metric: not computable (above). Report median |error| too.
- **Energy and limits check (must pass, no tolerance tuning):** on V1 laps, rear braking power ≤ 350 kW·(1+1e-6) at every point;
  drive power ≤ session kW; lap energy closes: E_out − E_regen − E_friction − E_drag − E_roll = ΔKE ≈ 0 over a closed lap,
  |residual| ≤ 0.1 % of E_out.
- **Compute time (central 4):** simulateLap time of the FE page car with the hook on ≤ 1.2 × off (median of 20 runs, 3 tracks).

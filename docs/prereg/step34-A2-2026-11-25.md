## 3. IMSA noise floor (estimator fixed now)
Data: `-laps.csv` of the same archive commit (lap by lap: time, sectors, pit flag, flag, driver). **Split-half repeat**, qualifying
sessions:
- push laps of one car and driver: green flag (FLAG_AT_FL = GF), not crossing into the pit, not the first lap after a pit stop or of the
  session, ≤ 102 % of that car-driver best; ≥ 4 push laps.
- push laps in time order split odd/even; d = ln(best_odd / best_even) (exchangeable → mean 0, no centring).
- σ_split = 1.4826 · MAD(d) / √2 = noise of a best-of-about-half lap (≤ single-lap noise); per class (lmh/lmdh by maker as
  fit-endurance, gt3 = GTD/GTDPRO/LMGT3, lmp2) and series; same on S1/S2/S3; 90 % event bootstrap, seed 20261125, 2000 draws;
  ≥ 20 cars over ≥ 3 events else "no estimate".
- Run on IMSA, WEC and ELMS; WEC split-half is a cross-check of the A1 Q → Hyperpole σ_rep (reported side by side).
- Reproducibility: script + archive commit; the derived per-car table is committed and sha256-pinned for the pipeline's noise-floor
  step. (Central asked for an Actions fetch; the session reads the same public archive at a pinned commit: same bytes.)

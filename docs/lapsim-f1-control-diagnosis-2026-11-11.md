The full historic gap is not causally isolated.** The four-arm sweep has finished and passed artifact/replay checks. Read the [verified curve](lapsim-owner-round-curve-results-2026-11-11.md). Production's stored F1 seasons are exactly equal to the export at `9fb675e2cb60de4ee5e2d395af5acabf45740e73`, generated by [run 42398451242](https://github.com/kangjeongmin1229/f1-data-analyst-deploy/actions/runs/42398451242) from source `6218a3633239630faf89cfa38fc94a7585b037a6`. Commit [`ffbfcafd583c26243ef46342f13ebe286019e307`](https://github.com/kangjeongmin1229/f1-data-analyst-deploy/commit/ffbfcafd583c26243ef46342f13ebe286019e307), after that fit, enabled causal 2026 battery state-of-charge by default: empty battery stops deployment, recovery is capped and overflow is discarded. ## Zero-optimizer kernel sensitivity check

Hold each final control fold's fitted car, factors and team adjustment fixed. Replay under the old kernel and current kernel. Turning off only causalSoc in the current kernel reproduces the old kernel at all 34 tested laps within 1e-9 seconds. This isolates that code path at the fixed current states; it does not recover historic production fold fits or identify the whole held-out RMS gap.

| Season | n | Current held-out RMS % | Old kernel, same current states RMS % | Mean current-minus-old s | Largest absolute lap change s |
|---|---:|---:|---:|---:|---:|
| 2025 | 20 | 0.841682 | 0.841682 | 0.000000 | 0.000000 |

The old-kernel replay does **not** return the stored production score. This is expected: the cars/factors were optimized with the current kernel and fold stopping. It would be wrong to subtract these RMS values and claim an attribution of the historic gap.

## Verified curve

See the [curve, in-sample errors, fold trajectories and stop audit](lapsim-owner-round-curve-results-2026-11-11.md). This measures the current kernel with the production fold rule. It does not recover old production fold states.

The verified current-kernel 2026 curve is 1.305853%, 1.197254%, 1.194867%, 1.180112% for main counts 3,4,5,6 with production fold counts 2,3,4,5 (n=14 throughout). Both tested seasons improve across that range. Restoring production's 5/4 counts gives 1.194867%, not the historic approximately 0.900%. The mixed 5/6 baseline is only -0.000721 pp from that 5/4 result, and +0.014033 pp from all-five-round folds. Thus changed stopping does not explain the large historic gap. A small sixth-fold-round worsening exists, but it is not proof that track factors alone overfit or that the main five-round limit supplied the claimed brake. Read the paired fold table in the curve report. No rule or model is adopted.

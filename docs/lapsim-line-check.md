Result: the line changes the top speed very little (trap check unchanged), but with the grip calibrated on the reference path it makes laps 3.5 to 5 % too fast. So the page keeps the lap time on the calibrated reference path and uses the line only for the map and the relative gain (s vs the least-curvature line). Making the line drive the lap time needs grip refitted on the line (not done: it would change the 0.000 % pole reproduction).
